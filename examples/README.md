# Examples

Integration samples for `@basis-theory/web-push-provisioning`.

- [`wallet/`](wallet/README.md): a runnable wallet page with the Visa container, both wallet buttons, the strong-authentication gate and result handling, plus the backend call that authorizes the session.
- [`mock/`](mock/README.md): the mock Visa web SDK the example and the end-to-end test run against.
